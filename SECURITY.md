# Security Policy

## Supported Versions

Security fixes go into the latest release only.

| Version | Supported          |
|---------|--------------------|
| 0.4.0   | :white_check_mark: |

## Reporting a Vulnerability

Please don't use public GitHub issues, discussions, or pull requests to report a security problem.

Report it privately
via [GitHub Private Vulnerability Reporting](https://github.com/sureshg/certkit/security/advisories/new) and include
whatever you have:

- Affected version or commit
- Steps to reproduce, or a proof of concept
- What an attacker could do with it

We'll confirm the report and keep you posted while a fix is worked on. Timelines vary with the complexity of the report,
maintainer availability, and when the next release goes out.

Thanks for reporting it privately.
